## ✨ Özellikler

- ⚡ **Anında Üretim:** Girilen metin veya URL'yi tek tıkla QR koda dönüştürür.
- 💾 **PNG İndirme:** Üretilen QR kodu doğrudan bilgisayarınıza veya telefonunuza PNG formatında kaydeder.
- 🚀 **Sıfır Kurulum:** Node.js, npm veya derleme adımı gerekmez; tek bir statik HTML dosyasından oluşur.
- 📱 **Mobil Uyumlu:** Sade ve temiz arayüz.

---

## 🛠️ Yerel Olarak Çalıştırma

```bash
# Depoyu klonlayın
git clone https://github.com/DarkMirrorq/simple-qrcode-generator.io.git
cd simple-qrcode-generator.io

# Herhangi bir tarayıcıda açın
open index.html   # macOS
xdg-open index.html # Linux
start index.html  # Windows
```
